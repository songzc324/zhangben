# 我的账本

一个纯本地的个人记账网页应用。无广告、无追踪、数据完全在你自己手里。

## 特点

- 单文件应用，无需安装、无需联网
- **打开即用、零授权提示**，记账自动保存
- 多账户分组：现金 / 储蓄 / 虚拟 / 投资 / 信用 / 负债 / 债权
- 信用卡额度管理（额度 / 已用 / 可用）
- 智能输入：说一句话自动识别金额、分类、账户
- 余额调整（对账）：直接填实际余额，自动算差额
- 账户流水：按账户查看全部流水，对账定位问题
- 报表 / 年报：月度和年度收支趋势、分类排行
- 可添加到手机主屏幕，全屏运行，体验等同原生 App

## 数据存储

数据保存在浏览器的**应用专用存储（OPFS）**里，属于持久化存储：

- 打开即用，无需点击任何授权按钮，没有弹窗打扰
- 每记一笔自动写入，清缓存、关浏览器、重启手机都不会丢
- 同时双写到浏览器本地库（IndexedDB + localStorage）作为副本
- 需要更保险时，可选开启「文件副本」，额外同步一份 json 到本地文件
- 支持随时手动导出 / 导入备份

## 使用

用 Chrome 打开网页即可。首次使用点右下角 **+** 记第一笔账。

## 说明

本仓库只包含程序本体，**不包含任何个人数据**。任何访客打开看到的都是一个全新空账本。
